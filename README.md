# THATTIKKO.FUN 🟢💛

> **Don't log in. Just Thattikko. 😉**

THATTIKKO.FUN is a simple, temporary way to send files and content from your **phone to a computer** without logging into personal accounts.

## ✨ Key Features

- 📱 Phone → Computer transfer
- 📄 Send files, images, text & code
- 🔢 Pair devices using a temporary code
- 🔐 No Google/WhatsApp login required
- 🧹 Temporary sessions with nothing left behind
- 💻 Designed mainly for shared and college lab computers

## 🛠️ Built With

- React
- TypeScript
- TanStack Router
- Supabase
- Tailwind CSS
- Vercel
